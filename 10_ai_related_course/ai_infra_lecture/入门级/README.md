# Token Factory：AI 推理的成本革命

## 1. 概述

本目录是一份 90 分钟技术普及讲座（2026 年 8 月版）的内容资产。讲座围绕一个核心主线：**一切 AI 基础设施优化的最终目标，都是降低每 token 成本**——沿"模型架构 → 硬件 → 推理引擎 → 基础设施与生态"四层杠杆展开，每层回答同一个问题：这层如何让 token 变便宜？

## 2. 内容资产

### 2.1 核心文档

- **[AI Infra 课程 PPT 大纲](./AI%20Infra%20课程%20PPT%20大纲.md)** - 40 页 PPT 大纲（每页含标题、内容要点、排版建议），是制作 PPT 的**单一数据源**
- **[讲稿](./讲稿.md)** - 552 行完整演讲逐字稿（85 分钟 + 5 分钟 Q&A），与大纲页一一对应

## 4. 制作 PPT

PPT 演示文稿由演讲者自行制作，内容以大纲为唯一数据源：

1. 每页 PPT 对应大纲的一个"第 N 页"章节（标题 + 内容要点）
2. 设计风格建议：深蓝主色 + 橙色强调（成本曲线）、16:9、科技感
3. 关键数据图表建议使用对数坐标（价格曲线、成本下降曲线）
4. 讲稿提供每页的口语化表达，可配合演讲使用
