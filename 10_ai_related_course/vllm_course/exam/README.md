# 结课考试卷

> 考试时间 120 分钟，总分 100 分（另设附加题 10 分）。闭卷；计算题需给出算式；简答按要点给分。

## 文件

| 文件                           | 用途                                      |
| ------------------------------ | ----------------------------------------- |
| [final-exam.md](final-exam.md) | 试卷（单选/多选/填空/计算/简答 + 附加题） |
| [answers.md](answers.md)       | 参考答案与评分标准（先做题，再对答案）    |

## 命题范围与依据

- 课程十讲（基线：nano-vllm `b9dd55a` + vLLM `2f5d8a2b1`，v0.34.1rc0-84）
- 本仓库相关深读：CXL 全景(`../../../01_hardware_architecture/pcie/08_cxl_interconnect_overview.md`)、NVLink 入门(`../../../01_hardware_architecture/nvlink/nvlink_intro.md`)、UCIe 4.0 对照(`../../../01_hardware_architecture/ucie/README.md`)、Marlin 深读等
- 真机实测发现（threshold 挂死、shm 三层坑）作为场景题素材

## 与课程考核的关系

结课卷是「限时检验」，与各讲 homework（过程性）和考核作业 1-4（项目性）并行。课程 README 的考核节建议：结课卷 30% + 作业 70%。自学者可只做卷子自评，不交作业。

## 使用建议

1. 先完成十讲学习与各讲 hands-on，再做本卷；
2. 计时 120 分钟，闭卷；
3. 对答案时，简答与论述按「要点给分」，答出参考要点之外的合理机制同样得分；
4. 分数低于 60：回看错题对应讲次，重学后再做一遍「变体卷」（把参数、模型、负载换成新值）。
