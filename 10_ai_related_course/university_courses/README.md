# 大学公开课档案

三门公开课各补一块能力版图：CS336 讲大模型本身（补全大模型基础），CMU 11-868 讲 LLM Systems（加强推理系统），Berkeley LLM Agents 讲 Agent 系统（加强智能体系统）。三门课的资源可访问性核实于 2026-11-19，课程随学期更新，引用其中内容前建议核对最新版本。

与 CS2680 同类的「agent + serving 双线」研讨课还有 UCSD CSE 291A、UMich CSE 585、Virginia Tech AgOS、Princeton COS 597k 等，均为论文研讨型，暂未建档。

## 课程一览

| 课程                                          | 定位                             | 形态                                 | 档案                                             |
| --------------------------------------------- | -------------------------------- | ------------------------------------ | ------------------------------------------------ |
| Stanford CS336 Language Modeling from Scratch | 大模型本身：从 tokenizer 造到 RL | 录像 + 5 个 GitHub 作业 + 交互式讲义 | [stanford-cs336.md](stanford-cs336.md)           |
| CMU 11-868 Large Language Model Systems       | LLM Systems：serving 单线动手    | 课程站 + 作业站公开，slides 未公开   | [cmu-11-868.md](cmu-11-868.md)                   |
| Berkeley LLM Agents（MOOC）                   | LLM Agents：agentic 工作流与安全 | 12 讲录像 + slides + quiz 全公开     | [berkeley-llm-agents.md](berkeley-llm-agents.md) |

三门课与 [哈佛 CS2680](harvard-cs2680/README.md) 的关系：CS2680 是唯一「agent + serving 双线合一 + 动手作业」的课；CS336 与 11-868 分别深入 CS2680 之下的大模型构建与 serving 工程两块，Berkeley 则把 agent 线展开成独立体系。
