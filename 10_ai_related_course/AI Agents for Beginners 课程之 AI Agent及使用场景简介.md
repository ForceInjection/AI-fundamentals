# AI Agents for Beginners 课程之 AI Agent及使用场景简介

> 核对日期：2026-11-19，基于上游仓库 main 分支（18 课版本）。课程仍在持续更新，引用具体内容前建议核对最新版本。

## 课程概述

`AI Agents for Beginners` 是一门由微软提供的课程，旨在帮助初学者全面了解 `AI Agent` 的构建与应用。课程当前包含 **18** 课，分两个阶段：前 10 课覆盖 `AI Agent` 的基础概念、开发框架、设计模式、工具使用、智能体 RAG、可信赖构建、规划、多智能体、元认知与生产部署；后 8 课为进阶专题，覆盖智能体协议（`MCP` / `A2A` / `NLWeb`）、上下文工程、智能体记忆、`Microsoft Agent Framework`、计算机操作智能体（`CUA`）、可扩展部署、本地智能体与智能体安全。

> 课程地址：`https://github.com/microsoft/ai-agents-for-beginners`

## 适用对象

本课程适合以下人群：

1. **初学者**：对 `AI Agent` 感兴趣，但缺乏相关经验的人员。
2. **开发人员**：希望将 `AI Agent` 技术应用于实际项目中的开发人员。
3. **数据科学家**：对 `AI Agent` 在数据分析和处理中的应用感兴趣的人员。
4. **研究人员**：从事 `AI` 相关研究，需要了解 `AI Agent` 最新发展和应用的研究人员。
5. **技术爱好者**：对 `AI` 技术充满热情，希望拓展知识面的技术爱好者。

## 先决条件

在学习本课程之前，建议具备以下基础：

1. **编程基础**：熟悉 `Python` 编程语言，了解基本的编程概念和语法。

3. **大语言模型基础**：了解大语言模型（`LLMs`）的基本原理和应用，如 `OpenAI` 的 `GPT` 系列模型等。

## 课程内容

### 第1课：AI Agent 及使用场景简介

本课介绍了 `AI Agent` 的基础概念、类型和应用场景。`AI Agent` 是通过为大语言模型（`LLMs`）提供工具和知识的访问权限，从而扩展其能力以执行操作的系统。其基本组件包括环境、传感器和执行器。环境定义了 `AI Agent` 运行的空间，传感器用于收集和解释环境的当前状态信息，执行器则根据任务需求执行操作以改变环境。本课新增「何时使用 AI Agent」小节，讨论适合智能体的问题形态（详见下文第 1 课详解）。

### 第2课：探索智能体框架

本课介绍了智能体框架的概念和作用。智能体框架为开发者提供预构建的组件、抽象与工具，简化智能体的创建、部署与管理：接线工具与能力、观测智能体行为并排障、多智能体协作。课程代码示例已全面切换到微软的 `Microsoft Agent Framework`（`MAF`）——`AutoGen` 与 `Semantic Kernel` 已不再出现于课程正文。

> **Microsoft Agent Framework**（官方文档：<https://learn.microsoft.com/en-us/agent-framework/>）: 微软的智能体开发框架，整合了 `AutoGen` 与 `Semantic Kernel` 两个前代的能力，用于构建生产就绪的智能体与多智能体工作流。GitHub 主仓（`microsoft/agent-framework`）在 2026-11-19 核对时尚未对外可见，Go 版实现见 `microsoft/agent-framework-go`。

### 第3课：理解智能体设计模式

本课探讨了智能体设计模式的概念和重要性。智能体设计模式是一种可复用的解决方案，用于解决智能体开发中的常见问题。通过使用设计模式，开发者可以提高代码的可维护性、可扩展性和可重用性。课程中介绍了多种常见的智能体设计模式。

### 第4课：工具使用设计模式

本课详细讲解了工具使用设计模式在智能体开发中的应用。工具使用设计模式关注的是如何有效地将工具集成到智能体中，使智能体能够利用这些工具完成复杂任务。课程中提供了具体的代码示例和实践指导。

### 第5课：智能体RAG（检索增强生成）

本课介绍了智能体 `RAG` 的概念和实现方法。`RAG` 是一种结合了检索和生成的技术，使智能体能够从大量数据中检索相关信息，并利用这些信息生成高质量的响应。这对于处理需要大量背景知识的任务非常有用。

### 第6课：构建可信赖的AI智能体

本课探讨了构建可信赖的 `AI` 智能体的重要性和方法。可信赖的 `AI` 智能体需要具备可靠性、安全性和透明性。课程中介绍了如何通过设计和实现来确保智能体的可信赖性，包括数据验证、错误处理、安全措施等方面。

### 第7课：规划设计模式

本课介绍了规划设计模式在智能体开发中的应用。规划设计模式关注的是智能体如何制定和执行计划以实现目标。课程中详细讲解了规划的步骤和方法，以及如何将规划集成到智能体的行为中。

### 第8课：多智能体设计模式

本课探讨了多智能体设计模式的概念和应用场景。多智能体系统由多个智能体组成，它们可以独立完成任务，既可以合作也可以竞争。课程中介绍了如何设计和实现多智能体系统，以及如何处理智能体之间的交互和协作。

### 第9课：元认知设计模式

本课介绍了元认知设计模式在智能体开发中的应用。元认知设计模式关注的是智能体如何对自己的思考过程进行监控和调整。这种能力使智能体能够更好地适应复杂环境和任务需求。

### 第10课：生产环境中的AI智能体

本课讲解了如何将 `AI` 智能体部署到生产环境中。这包括智能体的性能优化、监控、维护和扩展等方面。课程中提供了在实际生产环境中部署和管理智能体的最佳实践和建议。

### 第11课：使用智能体协议（MCP、A2A 与 NLWeb）

进阶专题第一课，介绍智能体与外部世界交互的三类协议：`MCP`（模型上下文协议，连接工具与数据源）、`A2A`（智能体间通信）与 `NLWeb`（自然语言网页交互）。

### 第12课：AI Agent 的上下文工程

本课讲解如何为智能体管理与工程化上下文——在有限的窗口内组织系统提示、工具定义、历史对话与检索内容，直接影响智能体的表现与成本。

### 第13课：管理智能体记忆

本课讨论智能体的记忆管理：短期记忆（当前会话）与长期记忆（跨会话的知识与偏好）的存储、检索与更新策略。

### 第14课：探索 Microsoft Agent Framework

对课程主用框架 `MAF` 的专题深入：架构、核心抽象与生产级智能体的构建方式。

### 第15课：构建计算机操作智能体（CUA）

本课讲解让智能体直接操作计算机界面（浏览器等图形界面）完成任务的 `Computer Use Agent` 模式。

### 第16课：部署可扩展的智能体

本课关注智能体系统的规模化部署：负载扩展、成本控制与运维实践。

### 第17课：创建本地 AI 智能体

本课讲解在本地环境运行智能体的方案——不依赖云端服务的模型与工具栈选择。

### 第18课：AI 智能体安全（Securing AI Agents）

本课聚焦智能体安全：威胁模型与防护实践，是第 6 课可信赖主题在安全维度的深化。

## 第1课：AI Agent 及使用场景简介（详解）

### AI Agent 基础概念

新版课程用一个直接的表述定义智能体：**AI Agent 是让大语言模型真正「做事」的系统——给它工具和知识，让它作用于世界，而不只是响应提示词**。每个智能体系统有三个核心部件：环境（智能体工作的空间，如预订平台本身）、传感器（读取环境当前状态的方式，如查询酒店空房或机票价格）、执行器（执行动作的方式，如订房、发确认、取消预订）。

在旧版「环境 / 传感器 / 执行器」三件套之上，新版补齐了两个关键要素：**记忆与知识**——智能体可以有短期记忆（当前对话）和长期记忆（客户数据库、历史交互），比如旅行智能体会「记得」你偏好靠窗的座位。这条要点与新增的第 13 课（智能体记忆）呼应。

### 何时使用 AI Agent（新增小节）

「能用」不等于「该用」。新版第 1 课给出智能体真正发光的三种场景：

1. **开放式问题**：解决问题的步骤无法预先编程，需要 `LLM` 动态规划路径。
2. **多步骤流程**：任务需要跨多轮调用工具，而不是一次查询或生成。
3. **随时间改进**：希望系统基于用户反馈或环境信号越来越聪明。

不适合使用智能体的场景，课程在第 6 课（可信赖的 AI 智能体）中展开。

### AI Agent 类型

新版课程用「旅行预订智能体」作为贯穿示例，七种类型如下：

1. **简单反射型 Agent**：按硬编码规则执行，无记忆无规划。例如看到投诉邮件直接转发客服。
2. **基于模型的反射型 Agent**：维护世界内部模型并随变化更新。例如追踪历史机票价格，标记突然变贵的航线。
3. **基于目标的 Agent**：心中持有目标并逐步规划如何达成。例如从当前位置出发预订整段行程（机票、租车、酒店）。
4. **基于效用的 Agent**：不止找一个解，而是权衡取舍找最优解。例如在成本与便利性之间平衡，找出最符合偏好的行程。
5. **学习型 Agent**：从反馈中学习持续改进。例如根据行程结束后的调查结果调整未来的预订推荐。
6. **分层 Agent**：高层智能体把工作拆解为子任务并委托给下层智能体。例如「取消行程」被拆成取消机票、取消酒店、取消租车三个子任务分别处理。
7. **多 Agent 系统（MAS）**：多个独立智能体协作或竞争。协作形态：分别负责酒店、机票、娱乐预订；竞争形态：多个智能体竞相以最优价格填满酒店房间。

### 智能体开发

构建智能体的第一步是定义它能做什么——工具、动作与行为。课程以 **Microsoft Foundry Agent Service** 为主要平台，它支持：来自 `OpenAI`、`Mistral`、`Meta`（`Llama`）等提供商的模型；`Tripadvisor` 等授权数据；标准化的 `OpenAPI 3.0` 工具定义。代码示例提供 `Python` 与 `.NET` 两个版本。

## 总结

`AI Agents for Beginners` 课程为初学者提供了一个全面学习 `AI Agent` 的平台。18 课版本相比早期的 10 课版本，把智能体协议、上下文工程、记忆管理、框架实战、计算机操作、规模化部署、本地化与安全补进了课程版图；代码栈也从 `AutoGen` / `Semantic Kernel` 并存切换到统一的 `Microsoft Agent Framework`。通过系统的学习和实践，学习者可以掌握 `AI Agent` 的构建和应用，为在人工智能领域的深入发展打下基础。
