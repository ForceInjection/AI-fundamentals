## 快速开始

- **完全零基础** → 路线图阶段 0 开始
- **会写代码但没写过 Agent** → 路线图阶段 1 开始，配套微软《AI Agents for Beginners》
- **已经在用框架、想懂原理** → hello-agents 第 4–7 章手搓范式
- **只想找参考项目** → 直接看 hub 清单第三、四节（Harness 与案例库）
- **遇到不懂的术语** → 查 [Agent 术语速查](glossary.md)
