## 二、开场（4 分钟，3 页）

**目标**：让全场在 60 秒内意识到"AI 的定价体系正在发生工业革命级的变化"。

**叙事草稿**：

> 今年 3 月，黄仁勋在 GTC 大会上给全球 CEO 看了一张图，然后说了句："数据中心不再是一台计算机，它是一个工厂——给工厂注入能量，产出的产品叫 Token。" 今天我想用 35 分钟，把这个"工厂"讲透。
>
> 先看两个数字。第一个：2023 年 3 月，GPT-4 的定价是每百万 token 输出 60 美元；2026 年 8 月，Qwen3.8-Flash 的同口径价格是 3 元人民币（约 43 美分）——单价三年跌了 140 倍。给个体积锚：100 万 token 大约是一部 75 万字小说的体量。上面报的都是**输出价**——让模型"写"出这么多字，三年前要 400 多块人民币，现在 3 块钱。这就是 140 倍的实感。而模型还越来越聪明：一次就做对、token 用得越来越少——真实场景的花费，降得比单价还要狠【素材 08 §1】。
>
> 第二个数字：2024 年初，中国每天消耗 1000 亿个 token；2026 年 3 月，140 万亿——两年，涨了约 1400 倍。这是**国家数据局今年 3 月发布的官方数字**【素材 05 §1.3】。给个直觉：这相当于**每天写 1.37 亿本《红楼梦》**（每本 73 万字），摊到 14 亿人头上，每人每天约 10 万 token、50 篇千字文【素材 07 注】。
>
> 价格往下、用量往上，这两个方向放在一起，像极了 140 多年前的电力革命：1882 年，爱迪生的珍珠街电站送出的第一度电，定价 24 美分——按通胀折算，相当于今天的 8 美元一度；而今天，美国一度电只要 20 美分左右。实际电价降了几十倍，电力产业的总产值却比蒸汽时代大了几个数量级。工业时代用"度"度量电，数字时代用 GB 度量流量，智能时代用 token 度量智能——**Token 就是 AI 的"度"**。所以今天的题目是：Token 工厂——AI 推理的成本革命。

**有用性前提（开场第一页，1 分钟——先回答"有没有用"，再亮两个数字）**：模型能力足够强、种类足够丰富——"有没有用"已经回答完了。四个事实【素材 08 §1/§2/§5】：

1. 规模：每月最大开源发布 754B–2.78T 参数；小米、蚂蚁、美团相继跨过 1T 线（美国同期 5/7 个月低于 130B）
2. 授权：DeepSeek、Z.ai 以 MIT 放出 700B–1.65T；中国 178 个超 20B 开源发布中，59% 采用 Apache 2.0、22% 采用 MIT
3. 生态：HF Hub 上托管 296 万个模型；Qwen 衍生模型共 151,448 个，是 Meta 的 2.6 倍、Llama 系的 4.7 倍，每天新增约 200 个；参数横跨 27B 至 2.4T
4. 实证：前沿闭源模型拒绝分析的攻击代码，量化开源 GLM-5.2 完成

落点：**"有没有用"不再是问题，问题是"怎么用"——接下来的故事：token 越来越便宜，用量越来越大。**（转场句不变，放在剪刀差页之后，衔接"什么叫 Token 工厂"）

**市场级价格信号（备料，口播可选 10 秒）**：Silicon Data LLM Token 支出指数（全市场按用量加权的平均支付价）跌至 **0.97 美元/百万**——历史新低、较夏季峰值腰斩【素材 12】——不是某个模型，是所有人付给所有模型的平均价。

**转场句**："在回答'成本为什么能革命'之前，先回答一个更基本的问题：什么叫 Token 工厂？它和我们熟悉的数据中心有什么不同？"

## 三、第一部分：什么是 Token 工厂（7 分钟，4 页）

**目标**：建立"从卖算力到卖智能"的产业认知；给观众三把分类尺子。

### 2.1 黄仁勋的三步叙事（1.5 分钟）

- 2022 提出"AI 工厂"：数据进、智能出；2025 升级："注入能量，产出 Token"；2026 GTC 宣布"推理经济"，新 KPI = Tokens/Watt（每瓦 token 产出），目标"Token 之王"【素材 02 §1】
- 关键画面：老黄的"一张图"——横轴 token 速率（聪明程度），纵轴每瓦吞吐（产能）；模型越聪明，速率越低，但 token 越值钱【素材 02 §2】
- 观众 takeaway：**Token 不是同质商品，是分层定价的**

### 2.2 Token 为什么能成为"货币"（1 分钟）

- 三个经济特征：可计量（token 数精确可数）、可定价（分层价格表）、可交易（按量计费）
- 类比：token 之于 AI，如"度"之于电力、"字节"之于流量——先有计量单位，后有产业；业界称之「智力服务的**千瓦时时刻**」（中国经济时报）【素材 02 §5】
- **国家级背书（一句话）**：2026 年 3 月，国家数据局给 token 定了官方中文名——「词元」，并把它纳入官方统计口径【素材 05 §1.3】——一个国家开始统计它的"度"了
- 观众 takeaway：**token 从技术单位变成了经济单位**

### 2.3 三把分类尺子（3 分钟）

1. **按规模**：个人/工作室（DGX Spark）→ 企业/主权级 → Gigascale（1GW、数百亿美元）【素材 02 §3.1】
2. **按商业模式**：聚合平台（"大模型界的 App Store"，整合各家 API 分销）vs 垂类 Token（把行业 Know-how 封装进 token 卖溢价）【素材 02 §3.2】
3. **按产业链位置**：算力运营方分成约 60–70% / 模型方约 20–30% / 应用方约 10–20%——利润重心在算力运营【素材 02 §3.3】

### 2.4 一个关键区分：Token 工厂 vs 智算中心（1.5 分钟）

- 传统数据中心是"算力房东"：卖卡时，利用率 30–50%，毛利率 20–30%，回本 3–5 年
- Token 工厂是"产品制造商"：卖产出，利用率 80%+，毛利率 40–50%，回本约 2 年【素材 03 §1】
- 一句话：**从"卖时间"到"卖产出"**——商业模式一变，账本全变
- 转场句："'回本 2 年、毛利率 50%'听起来很美——但这是别人算好的结果。我们自己把账算一遍，看看钱到底花在哪、赚在哪。"

## 四、第二部分：财务模型（8 分钟，4 页）

**目标**：带观众亲手算一遍账，建立成本结构的直觉，点破两个反直觉发现。

### 3.1 账怎么算：一个外行逼自己算懂 Token 经济（1 分钟）

- 引入方式：一个非财务出身的工程师，为了搞懂"建 Token 工厂能不能赚钱"，用 Excel 搭了 8 张表的测算工具（硬件投资 → 参数假设 → 财务测算 → 仪表盘 → 单卡经济 → 5 年现金流 → 情景对比 → 敏感性）【素材 01 全文】【素材 03 §2】
- 观众 takeaway：模型的价值不在答案，在"每个变量对结果的影响幅度"

### 3.2 核心公式与基准数字（2 分钟）

```text
年产出 = 单卡吞吐 × 3600 秒 × (8760 小时 × 利用率) × 卡数
```

- 基准：64 卡 × 2000 tok/s × 70% 利用率 → 年产出 **2.83 万亿 token（2825.6 亿）**；5 元/百万 → 年收入 1412.8 万元（注：素材原文"28.26 亿"为单位换算笔误，见 references/01 校正注）
- 成本：硬件投资 1918.4 万；年折旧 431.6 万（4 年、残值 10%）；年电费仅 49.5 万（PUE 1.4、0.75 元/kWh）
- 结果：净利润 431.9 万 / 回收期 2.22 年 / ROI 45%（现金流口径；净利润口径 22.5%）/ 盈亏平衡利用率 40.4%【素材 03 §2】
- 观众 takeaway：**一张 GPU 一年产约 440 亿 token——年收入 22 万、净收益约 9 万（毛利约 2 元/百万 token）**

### 3.3 产能与承诺：一天最多卖多少 token（1 分钟，新页）

- **Goodput（合规吞吐）**：只有「成功 且 体验达标」的请求产出的 token 才有人付钱——原始吞吐是假产能（不顾体验硬灌负载，刷出的是流失中的用户）；**可售卖产能 = 品质承诺刚被守住的极限工作点（λ_slo_max）**【素材 10】
- 先声明模型，再谈产能：**模型与配置**（规模 / TP·PP / 量化 / 缓存）与**单卡产能**同级——每个产能数字都绑定模型声明，同模型才可比，**跨模型只能换算成钱**（$/MTok under SLO）【素材 10】
- **模型选型 = 产能 × 通信税 × 单价**：Pro vs Flash 激活参数差 3.8 倍 → 单卡产能差 ~2×（官方实测，同卡数端到端理论上限 3.8×）；模型越大通信税越重——拓扑（NVLink/IB）决定税率，单节点可隐藏、跨节点拖死（AWS 实证 30×）；**产能报告必须写清"模型 + 配置 + 拓扑"**【素材 11】
- 老板视角的四个数（按模型分行）：**单卡产能**（SLO Goodput ÷ GPU 数）→ **集群日上限**（× 卡数 × 86400）→ **日产值**（× $/MTok under SLO，跨模型唯一可比口径）→ **支撑业务量**（日上限 ÷ 每 agent 步实测 ~247 tokens，并入落点条）【素材 10】
- **品质承诺 P99 体系**：TTFT 按 ISL 分档、ITL <100ms、成功率 ≥99.95%、Attainment ≥99%——agent 任务把违约**乘法放大**（单步 99% 达标 → 全链无感只剩 0.99^50 ≈ 60%），所以单步尾巴必须极窄【素材 10】
- Input 侧两个数：生产实测 input:output ≈ **294:1**、prefix 缓存命中 **~96%**——"总处理 input"是规模观瞻，"真实重算 input"才决定成本与容量【素材 10】
- 观众 takeaway：**对外卖的是承诺——"你的每个请求都快而稳"；对内考核一个数字——每张卡每天产出多少合格 token。两数必须一起报**（只有前者是赔本买卖，只有后者是自欺欺人）

## 五、第三部分：成本革命——在计算/存储/通信三维上的稀疏化（9 分钟，7 页，全篇技术核心）

**目标**：给出统一物理框架——token 的成本 = 计算 + 存储 + 通信，全部以能量计价；技术革命 = 在三维上做稀疏化；而能量不可稀疏化 → 产业终局是"每瓦 token"的竞赛。非技术观众带走直觉，技术观众带走框架。

> 讲解策略：每一维 = 一个压力 + 一个对策 + 一组数字，不展开机制细节。三个压力（参数越来越多 / 上下文越来越长 / 模型大到必须拆卡）与三维一一对应，结构天然自洽。

### 4.1 推理的本质与物理框架：一次生成在干什么（2 分钟）

- **两张画面（先给骨架，后讲优化——后面每个技术点观众都能对号入座"它在省什么"）**：
  - 读题（prefill）：把整个提问一次性读完、算完一遍，产出的"理解"存进显存——这份存档叫 **KV Cache**，一句话公式：KV 大小 ≈ 层数 × 头数 × 维度 × token 数（再乘 K/V 两份和存储精度）——**记住的东西随对话长度线性增长**
  - 逐字（decode）：每生成一个字，都要把全部存档和全部权重**重新读一遍，基于它们为下一个字做一次新计算**——每步都是一次"读 + 算"（这正是 KV Cache 的意义：避免每步全量重算，只算增量）
- **由此推出三维框架**（对应三个成本压力）：
  - 每步全量计算 → 算力（FLOPs）——参数越来越多 → 稀疏化（4.2）
  - 存档线性增长 + 每步重读 → 存储（容量 + 带宽）——上下文越来越长 → 压缩与复用（4.3）
  - 模型大到一张卡放不下 → 通信（卡内/卡间）——拆得越散 → 拓扑与本地化（4.4）
  - 三个维度都能"少做"，但最终都以**能量**计价——黄仁勋的 Tokens/W 是把三维压缩成一维的工厂 KPI（呼应第一部分）
- 成本底账（悬念，一句话级）：H100 输出硬件成本约 12.6 元/百万；零售端同一个 token 价差 250 倍（Claude 172.5 元 vs GLM 0.69 元）；DeepSeek 定价 5.18 元（V3.1）< H100 成本——它的账怎么做到的？→ 三维稀疏化【素材 03 §6】【素材 04 §0】
- 桥接句：**成本不是一个数，是一个随卡型、代际、优化水平移动的区间**——技术革命正在把整个区间往下压
- 观众 takeaway：**先有推理的骨架，再看优化——每个技术点都是对号入座：省算、省存，还是省传**

### 4.2 计算维：参数越来越多怎么办 → MoE + DSA + Engram（1.5 分钟）

- 压力：模型从 7B → 671B → 1.6 万亿参数；若每个 token 都过全部参数，成本线性爆炸
- **MoE（参数稀疏）**：671B 只激活 37B（5.5%——其余 94.5% 是"待命的专家"）；V4-Pro 1.6 万亿只激活 490 亿（**3.06%**）——每 token 只唤醒约 3% 的"脑细胞"【素材 04 §0.1】；术语类比：专家会诊——671 位医生，每次只叫醒 37 位
- **注意力稀疏（DSA）与条件记忆（Engram）**：学界有层深度路由思路 MoD（DeepMind 2024：简单 token 浅层通过）——但 **DeepSeek 官方未采用 MoD**，其路线是 DSA（只让值得的 token 参与注意力）与 Engram（"多少 token 不需要被理解？"查表替代理解）【素材 04 §0.1】
- 一句话：**智能不需要全部参数、也不需要全部深度——把算力花在最值得的 token 上**
- 观众 takeaway：**模型"变大"和"变贵"第一次脱钩了**（记忆数：3%）

### 4.3 存储维：上下文越来越长怎么办 → MLA / DSA / 复用（1.5 分钟）

- 承接 4.1 的存档公式（KV 定义已在 4.1 给出）：上下文 4K → 128K → 1M，KV 按长度线性增长、占显存 70%+；未优化集群成本 2–3 倍【素材 04 §1】
- **格式压缩 MLA**（类比：把记忆压成摘要存档，用的时候再展开）：KV 压进 512 维潜空间，省 **93%**；架构代际差 250GB → 5GB（V4-Flash 仅 2%）【素材 04 §0.2】
- **量化（精度压缩，半句带过）**：把每步要读的激活权重（671B 里被唤醒的 37B）压成 4 位精度，读取量从 74GB 降到 18.5GB——decode 是"读权重"的带宽游戏，读得越少跑得越快【素材 04 §0.2】
- **注意力选择 DSA 的跨维回声**（一句话）：还记得 4.2 的 DSA（只挑重点段落细读）吗？它省下的 98% 注意力计算，同时让"要读的存档"也少了——一个技术，两个维度一起省【素材 04 §0.2】
- **系统复用**（执行层）：PagedAttention——**显存版的操作系统虚拟内存**：KV 切块、按需放格、块表索引，碎片率 40–60% → 4% 以下（快递柜画面：装几格算几格，不为最长包裹包下整面墙）；前缀缓存命中率 93%+，命中 = 跳过 prefill 重算、边际成本趋零；小米全链路优化后 **API 降价 99% 仍收支平衡**【素材 04 §1.3】
- 一句话：**记忆不必完整（压缩后仍可恢复），也不必全部看（只读相关的）——推理降本的本质是"省记忆"，不是"省电"**
- 观众 takeaway：**2026 年"降价 99% 仍收支平衡"不是口号，是账本事实**

### 4.4 通信维与时间维：模型拆开的代价与利用率杠杆（1 分钟）

- 压力：模型大到必须拆卡——MoE 的 all-to-all（每个 token 跨卡找专家）、TP 的 all-reduce、PD 分离的 KV 搬运；**通信成为新瓶颈**（V4-Pro 每 GBps 带宽需 6.1 TFLOP/s 算力才能隐藏）【素材 04 §0.3】；类比：把团队拆到几个办公室，跨办公室的每次沟通都慢且贵
- **通信税（模型越大税率越高）**：切卡必须高速互联——单节点 NVLink（≈HBM 的 1/9）通信大部分可隐藏、接近理论；跨节点 IB（≈1/160）完全无法隐藏、产能拖死——**拓扑是产能数字的一部分**，模型选型直接决定税率【素材 11】
- 对策（"能不传就不传"的落地）：专家本地化（把专家放在常来的 token 旁边）、PD 分离（存档留在原地、只传结果；腾讯太极 16×H20 实测 15,800 tok/s，端到端 +30–40%）、拓扑感知调度
- **时间维（运营）**：连续批处理把利用率 30% → 70–80%——同样的三维消耗下产出翻倍；补上因果链：**延迟要求越苛刻 → batch 越小 → 利用率越低 → 单位成本越高**——把"延迟约束"接到第二部分"利用率第一杠杆"上
- 观众 takeaway：**同样的卡，调度与拓扑不同，产出差几倍**——这也是"技术派"玩家（清华系初创）的生存空间
- **白皮书实证（一句话）**：AI 质检动态批处理降本 55%、生物制药 PagedAttention 利用率提升 4 倍、异构算力整体降 30%【素材 07 §四】

### 4.5 能量的角色：三维共同的物理地板（1.5 分钟）

- 计算/存储/通信都能"少做"，但供电与散热是物理硬约束：**1GW 的工厂永远不会变成 2GW**——黄仁勋的原话是"值钱的不是算力，是**'每度电的智商'**"【素材 02 §5】
- 所以：数据中心选址从"网络枢纽"变"电力枢纽"（西部绿电）；电费占比随规模上升——折旧可摊薄、电力摊不薄（呼应第二部分口径之争）
- 硬件代际 = 物理地板的抬升：同一 1GW 数据中心两年 token 生成速率 **350 倍**（摩尔定律同期 1.5 倍）；GB300 每瓦 token 比 **Hopper 系（H100/H200）** 高 35–50 倍（黄仁勋先报 35 倍后承认故意保守，SemiAnalysis 实测约 50 倍）；Vera Rubin 官方口径为每百万 token 成本降至 Blackwell 的 1/10；液冷 PUE ≤1.1（白皮书口径）vs 传统 1.5–2.0【素材 04 §0.4】
- 诚实声明（防现场质疑，把诚实转化为论证资产）：**我引的数字分三类——官方定价可查、独立测算有交叉验证、厂商口径打折看**。350 倍是英伟达口径，SemiAnalysis 独立实测约 50 倍——方向一致；就算打一折，也比摩尔定律同期（1.5 倍）快 20 倍
- 趋势印证：白皮书四大趋势之首就是"算电深度绑定"——工厂选址优先风光/核电资源、自建微电网离网供电【素材 07 §六】
- 观众 takeaway：**三维稀疏化 × 每瓦产出——技术革命是乘法不是加法**（记忆数：350 倍）

### 4.6 价格瀑布：技术革命在账本上的结果（1.5 分钟）

- 时间线：GPT-4（$60 输出）→ GPT-4o mini（$0.6）→ DeepSeek R1（$2.19）→ Qwen3.8-Flash（$0.43，输出 3 元/百万）——单价跌 140 倍；而模型变聪明、token 用得少，真实任务的花费降得更多【素材 04 §4】
- **最新落点（同日双发，2026-08-26）**：智谱与阿里同一天发布 Flash 模型——GLM-5.3-Flash 同级智力 1/40 价、Qwen3.8-Flash 输入 1 元/百万（= DeepSeek V4-Flash 忙时输入价的 1/3）【素材 09 §三】——价格瀑布延伸到了"昨天"。**彩蛋（口播 10 秒，不进锚点）**：GLM 限时两周 5 折，输出 1.4 元/百万 ≈ GPT-4 输出价的 **1/300**——前沿智力第一次按"分"卖

- 结构性事实：输入/输出价差 1:1 → 1:8（GPT-3.5 → GPT-5）——**回扣开场那本小说：它用的是输出价——输出为什么贵？** 因为输出是串行自回归（快不起来）、输入可并行——技术革命也改写了价格结构
- **MTP 彩蛋（一句话，不作术语展开）**：连"逐字生成"这个串行瓶颈也在被攻克——新一代模型训练时学会"一次想好几步"：每轮多预判一个字、下一轮验证，对得上就白赚一步（MTP 多 token 预测，无需另跑小模型），DeepSeek V4-Flash 实测输出提速近 3 倍【本仓库 `09_inference_system/model_optimization/mtp-multi-token-prediction.md`】——技术革命没有停在 2026 年
- 点题：第二部分说"售价 3 元就亏"，第三部分说"输入 1 元、输出 3 元的目录价背后仍有 50–80% 毛利空间（公开分析口径）"——**不是市场疯了，是成本真的被革命了**（革命后的单位成本已低于 3 元生死线——成本是一个区间，技术革命把整个区间往下压）
- 转场句："价格跌了、用量反而暴涨——这两个反方向的力量是巧合吗？经济学 150 年前就预言了这件事：杰文斯悖论。接下来我们用几分钟拆开它，看看谁在变便宜，谁在变值钱。"

### 3.4 产能怎么度量：先找承诺的边界，再数 token（1 分钟，新页）

- **λ_slo_max 的工程读取**：从低到高逐档加压，**最后一个 PASS 的档位就是 λ_slo_max**——越过它，产出的都是违约 token
- **三阶段自适应压测**（实践中行之有效的方法）：
  1. 粗扫：到达率**几何递增**（×2：0.5 → 1 → 2 → 4 → 8），每档逐档判定 PASS/FAIL（四项：TTFT P99 / ITL P99 / 请求延迟 P99 / 成功率）
  2. 二分：在最后一个 PASS 与第一个 FAIL 之间二分逼近
  3. 长稳：临界档跑 30–60 分钟无退化——**对外承诺必须是长稳验证过的档位**
- **工具落地：AIPerf**（NVIDIA 开源，Apache 2.0）：一条命令拿到全套 P99 指标（TTFT/ITL/TPOT/吞吐）；内置自适应模式自动找 SLO 边界；生产 trace 回放（ShareGPT/BurstGPT/agentic traces）验证真实负载——**工具让"可签字"成为可能**
- 观众 takeaway：**可售卖产能 = 承诺守住的极限工作点——先找承诺的边界，再数 token**（延伸阅读：对外文档《Token 工厂的产能怎么算？》cluster-capacity-measurement.md）
### 3.5 反直觉发现 ①：折旧是电费的 9 倍（1.5 分钟）

- 大众直觉"AI 吃电"，账本说：电费不到总成本 6%，折旧占固定成本约 55%（总成本口径约 52%）
- 推论：**省电不如提利用率**——70% → 90%，产出和电费各涨约 29%，但折旧一分不动——新增的产出几乎全部变成利润；而电费砍半，利润只涨几个点
- 观众 takeaway：**"利用率"是这门生意的第一杠杆**——这也是后面第三部分技术革命的核心靶心

### 3.6 反直觉发现 ②：单卡的售价生死线（1.5 分钟）

- 每百万 token 全成本 2.96 元、毛利 2.04 元；**售价跌破 3 元，单卡即亏**【素材 03 §2】
- 但 Qwen3.8-Flash 的目录价是**输入 1 元/百万（约 0.14 美元）、输出 3 元/百万**——输入价已跌破 3 元生死线、输出价刚好打平【素材 09】——悬念：那厂商靠什么活？答案在第三部分
- **真实财报版（一句话）**：正在冲刺港股 IPO 的硅基流动，2025 年毛利率 **−24%**——每卖 1 元 token、算力成本花 1.24 元【素材 06 §1】——"跌破生死线"不是纸上模型，是真实利润表
- 观众 takeaway：**零售价已低于模型的"成本价"，一定有更深层的成本革命发生**

### 3.7 口径之争：看成本数据，先问一句：这房子买了几年（1.5 分钟，深刻点）

- 券商/专家口径：电力占 50–70%；模型口径：折旧是电费 9 倍——两种都对，场景不同：老集群折旧已摊完（电力占比高）；新集群在折旧期（折旧是大头）；边际口径 vs 全成本口径【素材 03 §5】
- 通俗化类比：问"买房月供占收入多少"——刚买房的人说房贷是大头，住了 20 年的人说水电物业是大头。折旧期不同，口径就不同
- 统一视角：**资本成本与电力成本同源**——都由"每瓦 token 产出"决定。功率是物理上限（1GW 的工厂不会变 2GW），每瓦产出越高，单位 token 的折旧和电费同时降。Tokens/W 不是营销话术，是把两个口径合并成一个数
- 口径补充（防现场追问）：本账本按**纯推理**口径——大厂工厂同时跑训练会稀释单位产出；固定成本中另有约 356 万的人工/租金/带宽/维护——不是只有折旧和电费
- 观众 takeaway：**听成本数据，先问"这房子买了几年"**

### 3.8 敏感性：三个要命的变量（1 分钟）

- 利用率、单卡吞吐、售价——任一关键变量明显恶化，项目就从盈利变亏损（保守情景：55%/3.5 元/1500 tok/s → 年亏 248.8 万、回收期 10.49 年；保守情景数字含 Excel 未披露细节假设，复算约 −182~−244 万）【素材 03 §2】
- **"利用率"歧义澄清（30 秒口播，防现场追问）**：行业里"利用率"有两种含义——① 设备利用率（并发度高不高、算力满不满，由 batch 驱动）② 时间占用率（一天有多少小时有活干，由需求/波峰波谷驱动）。财务模型的 70% 是**时间口径**；"单卡吞吐"已隐含设备口径（并发度高，实际速率才接近标称）——两个参数正交：一个管"有没有活"，一个管"有活时多快"
- **双驱动与飞轮预告**：吞吐 ← 并发度（技术/架构：第三部分的技术革命主要撬动它）；时间占用率 ← 需求（商业/定价：第四部分的杰文斯主要撬动它）——三根杠杆其实是同一个飞轮的环节：技术降本 → 降价 → 需求涨 → 时间占用率升 → 再降本（飞轮每圈都有损耗——需求弹性会衰减、新产能会分流——但方向是真实的产业正反馈）
- 转场句："账算完了，结论是：这门生意的命脉是两个数——每卡每秒产出多少 token，和成本压到多低。接下来 9 分钟讲清楚：这两个数，是怎么被技术革命掉的。"

### 4.7 市场旁证：价格还在跌（1 分钟，新页）

- **Silicon Data LLM Token 支出指数**（Bloomberg: SDLLMTK，全市场按用量加权的平均支付价）：跌至 **$0.97/百万**——历史新低、较夏季峰值**腰斩**、近 7 天 −8.6%
- **口径警示（口播一句）**：这是"所有人付给所有模型的平均价"（含输入+输出、动态定价），与主线目录价锚点口径不同——只做"价格仍在下跌"的旁证，不进倍数
- 驱动：中国低价开源模型、OpenAI 降价、动态定价、token 生成成本下降（呼应第三部分）
- 供应商影响：价格通缩压缩收入、算力承诺固定——OpenAI/Anthropic 已提交 IPO 保密文件，定价权承压（呼应 5.2 价值上移）
- 观众 takeaway：**单价端：平均支付价跌破 1 美元还在跌；用量端：两年 1400 倍——杰文斯的两端都在加速**【素材 12】

## 六、第四部分：革命之后发生什么（7 分钟，4 页）

**目标**：给出全篇的"反直觉高潮"（价格跌、盘子涨），落到每个听众可带走的结论。

### 5.1 杰文斯悖论：为什么价格跌、用量反而暴涨（2.5 分钟）

- 经济学经典（150 年前的预言）：煤便宜了，用量多了，总开支反而涨【素材 05 §1】
- **互动设计**："单价跌了 140 倍——你们猜，这个行业的**总盘子**是涨了还是跌了？"停顿 3–5 秒，再给数据（问题与数据对齐：用量 ×14 / Google ×134 / 中国 ×1400）
- AI 实锤数据【素材 05 §1.3】：
  - OpenAI Luna 降价 80% → 两周调用量 **×14**、收入 **+34%**（TD Cowen / OpenRouter 数据）
  - Google 月 token 处理量：9.7 万亿 → 1300 万亿（约 134 倍）
  - 中国日均：1000 亿 → 140 万亿（两年约 1400 倍）
  - （备用数据，口播可略：Terra 降价 20% → 用量 ×5、收入 +45%；IDC 五年 3 亿倍口径互斥见素材 05；微软 Q1 FY2026 处理超 100 万亿 token、同比 5 倍）
- 机制：消耗主体从"人"变"机器"——Agent 干一件事调用模型 10–20 次，token 用量是普通对话的 5–30 倍（Gartner）；HF Hub agent 流量实测：2026 年 4 月 Claude Code 一家占 67.8%，7 月降至 44.4%、Codex 升至 20.8%——份额此消彼长不是 Agent 退潮，是十多个新客户端涌现、生态分化【素材 08 §4】
- **飞轮回扣（20 秒）**："还记得第二部分末尾那个飞轮吗？技术让成本降下来是第一段，刚才这些数字是第二段——降价让需求起飞；需求涨了，工厂的时间占用率就上来了，成本还能再降。它正在转。"
- 深刻点：**"单 token 价格归零"不可怕，可怕的是"价格跌但用量停滞"**——目前没发生
- 观众 takeaway：**成本革命的最大受益者不是消费者，是整个产业盘子**

### 5.2 竞争维度的迁移：从"谁的 GPU 多"到"谁的 token 值钱"（1.5 分钟）

- 第一层：效率竞争——比每瓦 token（成本端）；黄仁勋"1GW 工厂 15 年摊销 400 亿美元，必须放最强机器"【素材 02 §2】
- 第二层：价值分层——token 分层定价（免费 / $3–6 / $45 / $150）【素材 02 §2】；垂类 token 溢价（行业 Know-how 封装）
- 第三层：生态卡位——聚合平台（App Store 逻辑）、Token 运营商（中国电信 9.9 元套餐、算力网入"六张网"、首个百亿级 Token 工厂集采 164 亿）【素材 05 §4】；"Token 出海"——算力留国内、价值跨境流，国产芯片市占 41%（2025）、Token 价格仅海外 1/6–1/10【素材 07 §三/§五】
- 类比：电力产业最终不是卖电赚钱，是卖电器、电网、电网服务——**AI 的价值也在从 token 本身，上移到 agent、工作流、行业方案**
- 观众 takeaway：**竞争的胜负手从"算力"转移到"效率 × 生态"**

### 5.3 结构性风险：折旧陷阱（1 分钟，讲"冷静"）

- 重资产 + 技术迭代快 = 资产快速贬值：作者原话是"今天的 5 元/百万，明年 4.75，后年 4.51"——5% 年降幅看着温和，但折旧按 4 年直线摊，市场价击穿成本价只是时间问题【素材 01 结尾】
- **上市公司版（一句话）**：纳斯达克的 CoreWeave 毛利率 66%，却净亏 6.26 亿美元——单季折旧 14 亿 + 利息 6.4 亿，把毛利吃得干干净净【素材 06 §2】——这就是"重资产"三个字的重量
- 对策趋势：不买卡只租卡（聚合平台）、买"效率"而非"卡数"（等新架构）、政府/电信长周期玩家入场（集采摊薄）
- 观众 takeaway：**别把重资产当护城河，效率与生态才是**

### 5.4 落点：给非技术听众的三条带走结论（1.5 分钟）

1. **看 AI 产业，别再看"模型多聪明"，看"每瓦 token 产出"和"单位 token 成本"**——这是新的度量衡
2. **成本革命 = 普及革命**：当 token 便宜到"手机流量"级别（戴文渊："百万 token 一分钱"，或等三年），AI 才真正普惠——用量 1400 倍增长才刚刚开始【素材 03 §4】
3. **机会不在"更便宜的 token"，在"更值钱的 token"**（垂类、Agent、行业方案）与"更大的市场"（基础设施、电力、配套）

## 七、结尾（1.5 分钟，1 页）

**叙事草稿**：

> 回到开场那张图。珍珠街电站送出的第一度电，点亮了几条街；140 多年后，电已经成为文明本身的基础设施，实际电价在通胀调整后降了几十倍——而电力产业的总产值，远超所有人的想象。
>
> Token 正在走同样的路：单价三年跌了 140 倍，用量两年涨了 1400 倍。Token 工厂的成本革命，把 AI 从"奢侈品"变成"基础设施"。价格终将趋近于零，而总产值**可能**超过今天所有软件产业的总和。
>
> 所以问题从来不是"token 贵不贵"，而是——**你的转化效率高不高，你的 token 值不值钱**。谢谢大家。
