# 素材：AI Factory 的定义、分类与产业格局

> 用途：支撑演讲第一部分「什么是 Token 工厂」。所有条目标注来源，演讲前请复核数字时效性。

## 一、定义

- **Omdia 定义**：AI 工厂是"以生产智能为目标的新型工业基础设施"，输出企业级 AI 能力、智能体与 Token 生产能力，而非传统计算资源——与传统数据中心（提供服务器/存储/网络）和智算中心（提供 GPU 算力）本质区分。来源：百度百科「AI工厂」词条。
- **黄仁勋三步叙事**：
  - 2022 年首次提出：AI 数据中心处理海量连续数据以训练和完善 AI 模型——"原始数据进来，经过提炼，然后智能输出，企业正在制造智能并运营大型 AI 工厂"。
  - 2025 年升级：AI 已像互联网和电力一样是基础设施；"给 AI 工厂注入能量，就会生产出非常有价值的产品，这些产品就叫作 Token"——英伟达从 GPU 公司演变为 AI 工厂公司。
  - 2026 GTC：AI 从训练时代全面进入"推理 + 智能体 + 物理 AI"的工业化时代（推理经济；台湾媒体译作"推论经济"——inference 的台译）；数据中心从 IT 基础设施转型为以 Token 为单位持续产出的"Token 工厂"；提出 **Tokens/Watt（每瓦 Token 产出）** 作为新 KPI，追求全球最低每 Token 成本，目标是"Token 之王"。
  - 来源：CIO Taiwan《AI 進入推論經濟時代 黃仁勳：資料中心轉型「Token 工廠」》、澎湃新闻 GTC2026 报道。
- **五层蛋糕架构**（黄仁勋）：能源 → 芯片 → 基础设施 → 模型 → 应用。基础设施层（土地、供电、冷却、建筑、网络、处理器编排系统）就是"AI 工厂"。芯片工厂、计算机组装厂、AI 工厂正成为人类历史上规模最大的基础设施建设。来源：CIO Taiwan 解读文。
- **Token 工厂操作性定义**（TokenFactory 白皮书 2026，九章云极联合 InfoQ）：以大规模 GPU 算力集群为底座，整合电力、液冷、高速网络与大模型推理优化技术，工业化、标准化量产 AI Token 的新型算力基础设施；"电力 + 芯片 + 数据 + 算法"输入、标准化 Token 输出的智能生产线。来源：搜狐转载《TokenFactory（词元工厂）技术与产业发展白皮书 2026》。
- **Token 的经济特征**：可计量、可定价、可交易三大特征；兼具信息单位、算力消耗单位、商业化计费单位三重身份。来源：TokenFactory 白皮书。

## 二、黄仁勋的"一张图"（Token 工厂经济学）

- 坐标：横轴 = Token 速率（每秒生成多少 Token，代表 AI"聪明程度"）；纵轴 = Token 吞吐量（每瓦产出多少 Token，代表"工厂产能"）。
- 核心关系：模型越大、上下文越长、思考越深 → 速率越低，但每个 Token 越值钱。
- **四层定价模型**：

  | 层级 | 价格 | 定位 |
  |---|---|---|
  | 免费层 | $0 | 高吞吐、低速率，用来获客 |
  | 中间层 | $3–6 / 百万 Token | 服务普通用户 |
  | 高级层 | $45 / 百万 Token | 大模型深度推理 |
  | 超高速层 | ~$150 / 百万 Token | 超长研究任务、关键路径实时响应 |

- 核心逻辑："每瓦性能决定了一切"——数据中心功率是物理约束（1GW 的 AI 工厂永远不会变成 2GW）；固定功率下每瓦 Token 产出越高，Token 成本越低。吞吐量 = 产能，速率 = 产品价值。
- **1GW 工厂的资本重压**：黄仁勋举例，建一个 1GW 工厂，即便什么都不放，15 年摊销成本也高达 **400 亿美元**，因此必须运行最强的计算机系统才能获得最低的 Token 生产成本。
- 来源：投资界《Token工厂经济学：老黄教全球CEO看一张图》（pedaily）。

## 三、分类框架

### 3.1 按规模（CIO Taiwan 分类）

- **个人与微型工作室级**：开源框架（OpenCLAW）+ DGX Spark / DGX Station 桌边 AI 超级电脑，5 人工作室即可打造 AI 助理。
- **企业级与主权 AI 工厂**：处理金融、医疗等机敏数据，NemoCLAW 沙盒机制保障安全；一台 A100 地端服务器首年成本约 3.74 万美元可处理每日十万次查询。
- **Gigascale 跨国巨型工厂**：高达数十兆瓦算力、动辄数百亿美元；黄仁勋警告"你最好确保放进去的是最棒的运算系统"。
- 来源：CIO Taiwan《解碼「AI 工廠」》。

### 3.2 按商业模式（长江证券）

1. **聚合平台模式**：相当于"大模型界的 App Store"或"AI 算力聚合路由平台"，自身不训练模型，通过统一中间层整合各大厂商 API，为开发者提供一站式调用。
2. **垂类行业 Token 模式**：拥有行业 Know-how 的软件公司将行业数据和经验封装进 Token，生产更具行业生产力的垂类 Token，获取更大利润空间。

### 3.3 按产业链位置（分成结构）

- 算力运营方（算力 + 电力 + 运维）分成 **60–70%**；模型方 **20–30%**；应用方 **10–20%**。来源：九方智投行业洞察。
- 玩家图谱：技术派（清华系初创，算法调优、算子优化见长）vs 资源派（上市公司依托政府区位与运营商合作经验，从裸金属向 Token 工厂转型）。典型：趋境科技（半年融资超 10 亿元）、魔形智能（成立两年日 Token 调用量数万亿级）、范式、硅基流动、无问芯穹。来源：智东西专访、Token 工厂专家交流。

### 3.4 按逻辑架构分层（长江商学院梅丹青）

底层电力/冷却/机房/网络 → 芯片与加速器 → 云平台/推理引擎/调度系统/安全治理 → 通用基础模型、行业适配、知识库、Agent 编排 → 真实业务场景。

## 四、全球格局

- Omdia 预测 **2026 年全球 AI 基础设施资本支出将超 6000 亿美元**；高盛估计可能从 2026 年的 7650 亿美元增至 2031 年的 1.6 万亿美元。来源：中国青年网财经观察、新浪财经引高盛。
- 阿里云宣布"建设中国最大的 AI 工厂"，是国内唯一在芯片、智能体云、模型、模型服务平台、智能体应用"全栈五层"均有布局的公司。来源：环球时报财经观察。
- 百度李彦宏提出"日活智能体数（DAA）"作为 AI 时代新度量衡；德勤预测 2028 年美国大规模运营 AI 工厂。来源：环球时报财经观察。
- 中国瓶颈在算力（高端芯片进口受限），国产芯片（寒武纪、昇腾、海光、沐曦、壁仞）经优化后性价比达可用状态，成为新主线。来源：Token 工厂专家交流。
- 黄仁勋：2027 年英伟达营收预计至少 1 万亿美元（2025 GTC 时是 5000 亿美元高确信需求）。来源：投资界。

## 五、Token 类比的业界标准表述

> 用途：为"Token 是 AI 的'度'"提供权威背书与严谨边界。三大主流类比方向：

1. **电力/千瓦时（与演讲一致）**：
   - 中国经济时报：「词元经济：智力服务的**"千瓦时时刻"**」——电力因有了千瓦时这个标准化度量单位，才从实验室奇迹变成可交易商品；词元正是智力服务的千瓦时，让认知劳动变成可计量、可定价、可交易的服务单元。
   - 三段式标准句式（腾讯云开发者社区《Token 经济学七问》）：「工业经济时代用千瓦时度量电力，数字经济时代用 GB 度量流量，智能经济时代用 Token 度量智能。」
   - 黄仁勋（Dwarkesh Podcast）："The input is electron, the output is tokens"（输入电子、输出 token）；36氪报道黄仁勋金句：「值钱的不是算力，是**"每度电的智商"**」。
   - 「电力跨不过国境线，但 Token 可以」——"电不出境、价值远航"，可用于第四部分价值迁移。
2. **货币/结算单位**：国家数据局局长刘烈宏：Token 是"智能时代的价值锚点"、"连接技术供给与商业需求的结算单位"；清华大学杨斌教授建议译名"模元"（兼具信息单位、算力单位、货币单位三重属性）。
3. **商品/石油**：黄仁勋称 Token 是"新的大宗商品"；算力 = 新石油、数据中心 = 炼油厂的类比（"数字电力"说）。
4. **严谨边界（人民日报客户端警示）**："世上有油，但没有'升'；有电，但没有'度'"——Token 只是计价单位，不是可囤积的实体资源；真正的稀缺资源是算力和高质量数据。Token 一词多义：AI 领域"词元"（计量单位）、区块链"代币"（权益凭证）、网络安全"令牌"（身份凭证）——"囤词元暴富"是偷换概念。
