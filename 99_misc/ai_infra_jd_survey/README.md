# AI Infra / Agent 岗位 JD 数据集

AI Infra / Agent 相关「研发｜测试｜运维」岗位 JD 的结构化数据集，用于后续多维度分析（技能词频、公司对比、方向差异、海内外对照）。采集日期 2026-11-18。

**导读文章**：[01-岗位技能版图.md](01-岗位技能版图.md) — 312 条 JD 的采集方法、市场分类、技能谱系与四条学习路线。交互版可视化见 [visualization.html](visualization.html)。

## 数据文件

- `data/jd_2026-11-18.jsonl` — 主数据集，312 条（2026-11-18 采集，两轮合并），每行一条 JSON 记录

## Schema（每行一条）

| 字段               | 类型     | 说明                                                                                      |
| ------------------ | -------- | ----------------------------------------------------------------------------------------- |
| `company`          | string   | 公司名                                                                                    |
| `title`            | string   | 职位名（照抄原文）                                                                        |
| `category`         | enum     | `研发` / `测试` / `运维` / `SRE` / `算法` / `其他`                                        |
| `sub_category`     | string   | 细分方向：推理引擎 / 训练框架 / Agent平台 / GPU运维 / 智算中心 / 测试开发 / 大模型评测 等 |
| `location`         | string   | 工作城市                                                                                  |
| `employment_type`  | enum     | `社招` / `校招` / `实习`                                                                  |
| `level`            | string   | 职级（官网常缺，缺则空串）                                                                |
| `salary`           | string   | 薪资（如 JD 未写则空串，不推测）                                                          |
| `responsibilities` | string[] | 岗位职责，逐条照抄原文                                                                    |
| `requirements`     | string[] | 任职要求，逐条照抄原文                                                                    |
| `skills`           | string[] | 技能标签（vLLM / K8s / CUDA / Go / nvidia-smi / NCCL 等）                                 |
| `source_url`       | string   | JD 页面或快照 URL，可追溯                                                                 |
| `source_platform`  | string   | `官网` / `HN` / `YC` / `BOSS快照` / `文章` / `公众号`                                     |
| `captured_at`      | string   | 采集日期（ISO）                                                                           |
| `completeness`     | enum     | `full`（JD 全文） / `partial`（快照摘要，仅填可见字段）                                   |

## 数据来源分层

| 层  | 渠道                                                                                                      | 条数 | 完整度       | 说明                                 |
| --- | --------------------------------------------------------------------------------------------------------- | ---- | ------------ | ------------------------------------ |
| 1   | 国内大厂官网招聘接口/页面（字节/腾讯/蚂蚁/百度/美团/阿里/京东/快手/华为/月之暗面/智谱/拼多多/MiniMax 等） | 179  | full         | 任职要求与岗位职责全文               |
| 2   | HN「Who is hiring」月帖（Algolia API，2026-09 至 11）                                                     | 74   | full/partial | 海外 AI infra/agent 岗，自由文本拆解 |
| 3   | 聚合平台搜索引擎快照（BOSS/猎聘/脉脉）+ 公开分析文章                                                      | 55   | partial 为主 | 仅快照可见字段，已登录墙无法抓全     |

采集分两轮：首轮 HTTP/API 直抓（研发线、测试运维线、海外、聚合快照四通道），第二轮 Playwright 渲染补抓 SPA 站点（月之暗面/智谱/快手/华为/拼多多）。百度详情（登录墙）、米哈游（TLS 失败）、拉勾（WAF）、京东校园（Moka 加密）未产出，记录于会话留痕。

## 分析口径注意

- `completeness=partial` 的记录仅能做「有/无某字段」级统计，词频分析建议只用 `full` 记录的 `requirements`/`responsibilities` 文本
- 官网 JD 缺薪资属常态；聚合平台快照的薪资为快照口径，与实时数据可能不同
- HN 帖为自由文本，职责/要求由 JD 原文拆解，存在拆解粒度差异

## 后续分析方向建议

- 技能词频：研发 vs 测试 vs 运维三类的 `skills` 标签分布（vLLM/K8s/CUDA/NCCL 出现率）
- 公司对比：同一方向各公司要求的差异（如 GPU 运维岗各家对 NCCL/K8s 的要求）
- 海内外对照：HN 岗位与国内同方向岗位的技能栈差异
- 职级-技能矩阵：带 `level` 的记录做职级与技能要求的相关性

## 采集方法

四个采集通道并行：国内官网研发线、国内官网测试+运维线、海外 HN+YC、聚合平台快照。抓取纪律：职责/要求照抄原文不概括、`source_url` 必填可追溯、缺字段留空不编造、聚合平台只收搜索引擎可见快照与公开文章（不绕登录墙）。
